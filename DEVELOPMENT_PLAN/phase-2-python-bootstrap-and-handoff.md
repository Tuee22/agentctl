## Phase Objective

Portable pipx installation, raw Click command transport and only the Python work needed before Haskell exists: bootstrap directories, pinned ghcup/GHC/cabal, native source build and raw handoff. This phase's commands are modules of the discovered commands directory under the Governance-owned Click root (P0-24). Its native build discovers one build component per owner through a `cabal.project` package glob, so a later phase adds its own package without editing this phase's files, and the protocol and transport components carry no placeholder runtime commands.

This phase's verdict evaluates the `linux` half ([T.V](development_plan_standards.md#tv-verdict) V8) at stage 2 ([T.W](development_plan_standards.md#tw-staged-enforcement)). Every cited artifact is owned within closure(2) ([§ A](development_plan_standards.md#a-well-ordered-constructive-narrative)), a planned absence is unmet work of this phase ([T.F](development_plan_standards.md#tf-shared-and-owned-failures)), and present incompatible code is a deletion-ledger row of its owner. Native Windows bootstrap confirmation is owed to [Windows application acceptance](phase-11-windows-application-acceptance.md), and native Darwin bootstrap confirmation and the host-declared Darwin bootstrap module belong to [macOS acceptance](phase-13-macos-acceptance.md); neither is a gap in this verdict.
