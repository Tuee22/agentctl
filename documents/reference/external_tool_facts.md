# External Tool Facts

**Status**: Reference only
**Supersedes**: N/A
**Owning phase**: [Gate-integrity apparatus](../../DEVELOPMENT_PLAN/phase-1-gate-integrity-apparatus.md)

> **Purpose**: Record the verified facts about external tools that agentctl's decisions and oracles rest on, each with the tool version, the date it was verified and the command or source that verified it.

These facts describe tools agentctl does not own. The tools' own behaviour and documentation stay the authority; this
page records what was observed. Every row was verified on the date it gives, by running the command it names on the
verification host or by reading the source it names. Reports that could not be verified, and inferences drawn from the
facts, are left out.

**Citing a row.** An oracle row whose provenance is `tool:<name> <version> <source>` cites one row of this page:
`<name>` is the tool its section covers, and `<version>` and `<source>` are the row's own. The `tool:` decisions in
[rationale.md](../../DEVELOPMENT_PLAN/rationale.md#decisions) rest on rows here in the same way. A fact enters this page,
with its source, before any oracle row cites it, and verifying it again against another version adds a row beside the
old one, so a citation never changes meaning.

**Verification host.** Ubuntu 24.04.5 LTS on Linux x86_64, with claude 2.1.316 (native install), codex-cli 0.166.0 (npm
install), tmux 3.4, ghcup 0.1.50.2, GHC 9.12.4, cabal 3.16.1.0 and Python 3.12.3. pipx and psmux were not installed
there and no tmux server was started, so the pipx, psmux and tmux rows come from documentation and source code at the
version given; "local" in a source means a command run on this host.
